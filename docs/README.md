# home-garage docs

このディレクトリには、役割ごとに分割したドキュメントを配置しています。

## 読み分け

- `operations-guide.md`
  - 構築、検証、日常運用の手順をまとめたガイド
- `configuration-reference.md`
  - アーキテクチャ方針、repo 構造、sync wave、主要ファイルの役割をまとめた参照資料

## 推奨の読み順

1. まず `operations-guide.md` で CLI の使い方と構築手順を把握する
2. 次に `configuration-reference.md` で manifest と overlay の責務分離を確認する
